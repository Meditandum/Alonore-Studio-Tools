# Changelog

## 0.11.6 — UI stability preview
- Moved per-light randomizer locks into the selected-light settings.
- Improved readability of light names in Unified Light Manager.
- Reduced panel jumping when randomizing all softbox shapes.

## 0.11.5 — Light locks preview
- Added Position, Power, and Color randomizer locks for lights.

## 0.11.4 — Power randomizer fix
- Randomize relative to a captured base rather than repeatedly multiplying the previous result.
- Added **Set Current as Base**.

## 0.11.3 — Unified Light Manager preview
- Combined original and additional lights in one UI list.

## 0.11.2 — Dynamic lights and power randomizer
- Fixed UI data mutation during panel drawing.
- Dynamic light controls and power randomizer.

Earlier versions included presets, creative colors, adjustable softboxes, and LightPaint.
