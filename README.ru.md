# Alonore Studio Tools

Экспериментальный аддон студийного освещения для Blender. Автор проекта — **Alonore Art**.

**Текущая сборка:** v0.11.6 (предрелиз). Автор проверил её в **Blender 5.3 Beta**. В метаданных указана минимальная версия 4.2, но совместимость со всеми версиями не подтверждена.

## Возможности

- Создание студийной установки со светильниками и камерой.
- Unified Light Manager для стандартных и дополнительных Area / Point / Spot / Sun.
- LightPaint для исходных студийных светильников и сохраняемые маркеры.
- Софтбоксы, рандомайзеры положения, мощности, цвета и формы.
- Индивидуальные блокировки Position / Power / Color.
- Четыре встроенные световые схемы и шесть локальных слотов пресетов.

## Установка

1. Скачайте `alonore_studio_tools.py`.
2. В Blender откройте **Edit → Preferences → Add-ons → Install from Disk** (название команды зависит от сборки Blender).
3. Выберите файл и включите аддон.
4. Откройте боковую панель (`N`) в 3D Viewport, вкладка **Alonore**.
5. Выделите Mesh-объект и нажмите **Create Studio Setup**.

Перед обновлением сохраните резервную копию `.blend` и предыдущую версию аддона.

## Ограничения

- Стандартные и дополнительные источники света пока используют разные внутренние системы настроек.
- Часть рандомайзеров и LightPaint работает только со стандартными источниками.
- Шесть слотов пресетов не являются универсальным переносимым форматом для обмена всеми световыми установками.
- Онлайн-каталог и публикация пресетов пока не реализованы.
