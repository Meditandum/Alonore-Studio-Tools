# Contributing

Thank you for your interest in Alonore Studio Tools!

By submitting code contributions, you agree to license your contributions under **GPL-3.0-or-later**. Please ensure you have the right to submit all included code and assets.

For bug reports, provide Blender version, add-on version, OS, reproduction steps, screenshots where helpful, and the full traceback from Blender's system console.

For proposed changes, open an issue first, keep patches small, preserve existing `.blend` compatibility where possible, and explain how to test the change. Never mutate Blender ID data inside a `Panel.draw()` method.

This project is currently a single-file add-on; modularization is a future possibility, not a prerequisite for reporting bugs.
