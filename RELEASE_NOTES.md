# v0.11.6-beta — release candidate

This is a **pre-release** tested by the creator on Blender 5.3 Beta. It is not certified for every Blender version.

## Highlights
- Unified Light Manager with original and additional light sources
- Position, Power, and Color randomizer locks
- Fixed Power Randomizer baseline behavior
- Stable UI during All Shapes softbox randomization
- Legacy .blend project compatibility reported by the creator

## Known limitations
- Legacy and additional lights have different settings implementations
- LightPaint and some randomizers apply only to original lights
- No community preset sharing or online library yet
- Undo/redo and full save/reopen persistence require further testing

## Install
Download `alonore_studio_tools.py` from this release, install it through Blender Add-ons, and enable the add-on. Back up existing .blend files before upgrading.
